# Rock-Type Image Classification with Transfer Learning

A small, reusable PyTorch reference implementation for training and evaluating a four-class image classifier with a pretrained ResNet-18. It is a companion project to my bachelor's thesis, *Automated Recognition of Rock Types in Google Street View Images Using Transfer Learning*.

> This repository contains a clean reference implementation, not the original thesis code or dataset. The thesis result below was measured in the thesis experiment; it was not generated by this repository.

## Thesis context

The thesis explored classifying anthropogenic material, granite, limestone, and sandstone in realistic street-level imagery. It compared a frozen pretrained backbone with partial fine-tuning and used data augmentation, standard classification metrics, error inspection, and Grad-CAM to understand model behaviour.

The selected thesis model achieved **88.89% validation accuracy (224/252 images)** and received a grade of **8.5/10**. This is a result on the thesis validation split, not a claim about performance on new locations or this reference implementation.

## Run the reference implementation

Use your own appropriately licensed, labelled images. The expected folder layout is:

```text
data/
  train/
    anthropogenic/
    granite/
    limestone/
    sandstone/
  val/
    anthropogenic/
    granite/
    limestone/
    sandstone/
```

Install the dependencies and train:

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python train.py --data-dir data --epochs 10
```

The script fine-tunes the final ResNet-18 block and classification head, selects the checkpoint with the best validation accuracy, and writes a classification report and confusion matrix alongside the model checkpoint. It uses ImageNet pretrained weights, so the first run requires internet access to download them.

## Reproducibility and limitations

- Set `--seed` to make data-loader shuffling reproducible.
- Keep images from the same physical location or scene in only one split; random image-level splits can leak near-duplicates and overstate generalisation.
- Use a separate, location-separated test set for a final unbiased evaluation.
- This example is a starting point, not a production system. It does not include the thesis imagery, labels, or original training artifacts.
